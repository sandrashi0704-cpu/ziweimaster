# 紫微斗数排盘引擎 · Codex Skill

> 紫微斗数命盘排盘计算引擎，提供完整的排盘算法、四化系统、格局分析与古籍查询。

---

## 📌 概览

本项目是一个**紫微斗数排盘工具**，核心能力是**命盘计算与排盘**（输入出生时间 → 输出完整命盘）。

项目的定位是：

- **主要用法：作为 Codex 技能（Skill）安装使用** — 在 Codex CLI 中通过 AI 对话调用，AI 模型会根据命盘数据自动生成解读
- **附带的网页版：仅提供排盘计算功能** — 用于快速查看星曜分布，不做深度解读

命盘解读需要依赖**你自己的大模型（如 GPT、Claude 等）或你自己的 API**，本引擎只负责排盘计算部分。

---

## 🚀 推荐用法：安装为 Codex 技能（Skill）

> 这是本项目的**主要使用方式**。安装后，你可以在 Codex CLI 中通过 AI 对话直接使用。

### 前置条件

- 安装 [Codex CLI](https://github.com/openai/codex)
- 配置好你使用的大模型（由你自行决定用哪个模型）

### 安装命令

```bash
npx skills install sandrashi0704-cpu/ziweimaster
```

### 使用示例

安装后，在 Codex 中直接说：

> "帮我排一个命盘，1995年7月4日凌晨3点，女"

AI 会自动调用排盘引擎计算命盘，然后**由你配置的大模型**生成解读内容。

### 为什么推荐用技能形式？

- ✅ 解读质量取决于你使用的大模型，不受本工具限制
- ✅ 可以自定义解读风格和深度
- ✅ 无需搭建和维护网站
- ✅ 纯命令行操作，轻量高效

---

## 🌐 网页版（仅用于查看排盘）

> 网页版**仅提供排盘计算与星曜展示**，不做深度解读。
> 如需解读，请使用 Codex 技能形式，或自行接入大模型 API。

### 本地启动

```bash
git clone https://github.com/sandrashi0704-cpu/ziweimaster.git
cd ziweimaster
npm install
npm run dev
```

然后在浏览器打开 `http://localhost:3000` 即可查看排盘结果。

## 📖 功能介绍

### 排盘引擎核心能力

- 安命宫、定十二宫
- 十四主星布局
- 辅星（左辅、右弼、文昌、文曲等）
- 四化系统（化禄、化权、化科、化忌）
- 庙旺平陷亮度计算
- 大限排盘
- 格局识别（紫府同宫、杀破狼、机月同梁等）
- 三方四正分析

### 古籍原文查询

内置《骨髓赋》《全集》《全书》等紫微斗数经典古籍，支持原文检索。
