# 紫微斗数 · 命盘排盘与解读引擎

> 基于倪海夏《天纪》教学体系的紫微斗数排盘系统，提供完整排盘算法、四化系统、格局分析、古籍原文查询功能。

---

## 这是什么东西？

这是一个**紫微斗数命盘排盘工具**。你输入出生年月日时和性别，它就能算出你的紫微斗数命盘，显示十二宫、主星辅星、四化、大限流年等信息。

它有两种用法：
1. **当网站用**（适合普通用户）— 在电脑浏览器里打开就能用
2. **当 Codex 技能用**（适合开发者）— 在 Codex CLI 里用 AI 对话使用

---

## 用法一：当网站用（适合电脑小白）

这是最简单的方式，不需要懂编程。

### 你需要提前准备的东西

| 软件 | 说明 |
|------|------|
| Node.js | 运行本项目的环境。下载 https://nodejs.org （下载 LTS 版本，安装时一路点"下一步"即可） |
| Git | 下载代码的工具。下载 https://git-scm.com （Windows 下载后一路点"下一步"） |

不确定有没有装？打开"命令提示符"（Win+R，输入 cmd，回车），分别输入 `node --version` 和 `git --version`，有版本号显示就说明装好了。

### 安装步骤

第 1 步：下载本项目

打开命令提示符，输入：
```
git clone https://github.com/sandrashi0704-cpu/ziweimaster.git
```

第 2 步：进入项目文件夹
```
cd ziweimaster
```

第 3 步：安装依赖
```
npm install
```
这一步会自动下载项目需要的各种组件，需要等 1-2 分钟。

第 4 步：启动项目
```
npm run dev
```

第 5 步：打开浏览器
在浏览器地址栏输入 **http://localhost:3000** 回车，就能看到页面了！

注意：这个窗口不能关，关了就访问不了。想关闭时按 Ctrl+C 即可。

### 常见问题

Q：浏览器打开后一片空白或报错？
A：检查命令提示符窗口是否还在运行。如果报"端口被占用"，可以改成 `npx next dev -p 3001` 试试。

Q：怎么给自己排盘？
A：打开页面后找到表单，输入出生年月日时和性别，点击排盘按钮即可。

Q：AI 解读功能怎么用不了？
A：AI 解读需要你自己配置 API 密钥。如果你有 OpenAI 或 Anthropic 的 API Key，复制 `.env.example` 文件为 `.env.local`，在里面填入你的 Key 即可。

## 用法二：当 Codex 技能用（适合 Codex CLI 用户）

如果你在使用 Codex CLI，可以将本项目安装为技能，通过 AI 对话直接使用。

安装命令：
```
npx skills install sandrashi0704-cpu/ziweimaster
```

安装后，在 Codex 中直接说人话就能用，例如：
"帮我排一个命盘，1995年7月4日凌晨3点，女"

### 技能功能

- 紫微斗数完整排盘（安命宫、定十二宫、十四主星、辅星、四化）
- 命盘深度解读（事业、财运、感情、健康）
- 格局分析（紫府同宫、杀破狼等）
- 古籍原文查询
